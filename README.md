# Мир в 100 людях

Интерактивный просветительский лендинг о населении Земли. Данные проверены по публикациям ООН, ВОЗ, ЮНИСЕФ, ЮНЕСКО, МСЭ, ФАО, Всемирного банка и Pew Research Center.

## Запуск

Откройте `index.html` в браузере. Проект не требует сборки и внешних зависимостей.

## Публикация

Проект подготовлен как статический сайт для GitHub и Vercel.
